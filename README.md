# 📰 AI-Based Fake News Detection and Web Verification System

## 📌 Project Description

This project is an AI-based web application designed to analyze news entered by a user and search online news sources for supporting evidence.

The application uses Python and Streamlit and provides a simple interface for news verification.

## 🚀 Features

- Enter any news headline or claim
- Search online news coverage
- Analyze available sources
- Display supporting evidence
- Show REAL / FAKE / UNCERTAIN
- Display relevant news sources
- No Gemini or OpenAI API key required

## 🛠️ Technologies Used

- Python
- Streamlit
- Requests
- Pandas
- BeautifulSoup
- GDELT
- HTML/CSS
